💳 Bank Account System (Java)

This is a simple console-based banking system written in Java.  
I built this project to practice core programming concepts like Object-Oriented Programming (OOP), user input handling, and basic logic building.

---
 Features

1. Deposit money into account
2. Withdraw money with balance checking
3. View current balance
4. Display account details
5. Track transaction history
6. Handles invalid input (no crashes)

---
 Technologies Used

1. Java
2. OOP Concepts (Classes, Objects, Encapsulation)
3. ArrayList (for storing transactions)
4. Scanner (for user input)

---
 How to Run

1. Compile the program:
javac BankAccountSystem.java

2. Run the program
java BankAccountSystem

---
 Sample Flow

1. Enter account holder name and account number  
2. Choose options from menu:
3. Deposit money  
4. Withdraw money  
5. Check balance  
6. View account info  
7. See transaction history
